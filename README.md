# مصاريفي

## المزامنة السحابية

1. أنشئ مشروعًا في Supabase.
2. افتح `supabase.sql` وانفذ محتواه في SQL Editor.
3. انسخ Project URL و anon key إلى `js/cloud-config.js`.
4. أعد فتح التطبيق.

بدون إعداد Supabase، يستمر التطبيق باستخدام التخزين المحلي. استخدم anon key فقط، ولا تضع service role key في الواجهة.

نظام بسيط لمتابعة المصاريف اليومية بالدينار البحريني.

## التشغيل

افتح `html/index.html` في المتصفح، أو شغّل خادمًا محليًا من مجلد المشروع:

```bash
python -m http.server 4173
```

ثم افتح `http://localhost:4173/html/`.

## النشر التلقائي على Netlify

ارفع المشروع إلى GitHub، ثم اربط مستودع GitHub مع Netlify. استخدم إعدادات `netlify.toml` الموجودة في الجذر، ولا تحتاج إلى Build command. بعد الربط، كل `push` جديد إلى GitHub سيشغّل Deploy تلقائيًا ويحدّث الموقع.

الموقع لا يتحدث تلقائيًا من ملفات جهازك مباشرة؛ يجب حفظ التعديل ثم عمل `git push` حتى يصل إلى Netlify.

## الهيكل

- `html/`: صفحات التطبيق.
- `css/`: reset والتخطيط ومكونات الواجهة.
- `js/`: الإعدادات والتخزين والواجهة ونقطة التشغيل.
